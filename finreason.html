Reading the rule instead of the filing读规则，而不是读财报

A deterministic XBRL audit-verification system: 98.38% on the development set against a 33.09% baseline, with no model at inference time. Test-set scores freeze on 16 October.确定性的 XBRL 财报审计核验系统：不调用任何模型，开发集准确率 98.38%，官方基线 33.09%。测试集成绩 10 月 16 日定格。

What the system decides系统判定什么

No model runs at inference. Each case is routed by the committee's own published rule logic, then checked with the computation that rule requires.推理时不调用任何模型。每道题先按规则委员会公开的规则逻辑分流，再用那条规则要求的算法去核验。

The task任务

Each case is an SEC XBRL filing and two questions about one concept: what the filing reports, and what its own calculation relationships imply. Every case is built around a flagged data-quality rule, so the two numbers always disagree.

每道题是一份 SEC XBRL 财报加两个问题：财报报的数字是多少，按它自己的计算关系推出来应该是多少。每道题都来自一条被触发的数据质量规则，所以两个数字一定对不上。

Finding 1发现一

The reference parser resolves calculation locators from the label attribute, which silently returns nothing when filings omit a separator. Resolving through xlink:href instead moved the dominant rule from 30.82% to 93.10%.

官方基线从 label 属性里解析定位符，财报少写一个分隔符时会静默返回空。改成从 xlink:href 解析后，占比最大的那条规则从 30.82% 提到 93.10%。

Finding 2发现二

The three data-quality rules need three different computations, and the committee's own published rule logic tells them apart: 54 of 54 dimensional cross-check cases carry a whitelisted axis, 0 of 34 others do.

三条数据质量规则需要三种不同的计算，而规则委员会公开的规则逻辑本身就能把它们分开：54 个维度交叉校验题全都带白名单坐标轴，其余 34 个一个都没有。

Five falsifications五条被证伪的假设

All reported in full, including that routing uncertain cases to a language model scored three cases worse than leaving them to the rules, and four ways the public practice set failed to predict the ranked phases.

全部如实报告，包括：把不确定的题交给大模型，反而比交给规则少对 3 题；以及公开练习集在 4 个方面没能预测正式阶段的表现。

Pre-registered: every change had a written hypothesis and threshold before it was run, and every experiment is in an append-only log.预注册：每个改动都在跑之前写好假设和门槛，所有实验都记在只追加的日志里。
